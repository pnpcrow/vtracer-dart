Needle3는 어떻게 판단할까?

1 · 이것이 무엇인가요?

AI 자동 모드는 "다이얼을 대신 돌려 주는 조수"

vtracer는 사진을 선과 곡선으로 된 그림(SVG)으로 바꾸는 변환기입니다. 결과 품질은 설정 다이얼 14개(색을 얼마나 세밀하게 볼지, 잡점을 얼마나 지울지 등)가 결정하는데, 정답은 없고 사진마다 알맞은 값이 다릅니다.

AI 자동 모드는 이 다이얼을 대신 돌려 주는 기능입니다. 사진의 성격을 숫자로 요약해 보고, 알맞은 설정 세트를 골라 슬라이더까지 움직여 줍니다.

Needle3는 그 판단을 맡은 아주 작은 AI 두뇌입니다. 모델 크기는 노래 한 곡 정도(8–35MB)라서 앱 안에 내장되어 함께 배포되고, 인터넷이나 서버 없이 기기에서 바로 실행됩니다.

비유로 이해하기

사진은 재료, 설정 다이얼은 간 맞추기입니다. Needle3는 재료를 살짝 보고 "오늘은 싱겁게, 소금은 2 꼬집!" 하고 알려 주는 요리 도우미입니다. 다만 마음대로 간을 하지 않고, 뒤에서 설명할 안전 확인을 거친 답만 주방에 들어갑니다.

2 · 적용 방식 — 1단계

사진을 "숫자 성적표"로 압축합니다

Needle3는 아주 작은 두뇌라서 사진 전체(수백만 개의 점)를 직접 볼 수 없습니다. 대신 vtracer가 사진을 17개의 숫자로 요약한 성적표를 만들어 전달합니다.

성적표에는 이런 항목이 적힙니다 — 색이 몇 종류인지, 잡음(노이즈)이 얼마나 끼었는지, 선이 얼마나 촘촘한지, 배경은 고른 색인지 등입니다. 사진이 아무리 커도 성적표는 언제나 같은 크기라서 판단이 아주 빠릅니다(약 0.1초).

왜 이렇게 하나요?

작은 두뇌에게 사진 원본을 주면 버거워하지만, 17개 숫자라면 금방 이해합니다. 성적표는 사람이 읽어도 이해할 수 있어서, 나중에 "왜 이 설정을 골랐는지"를 함께 볼 수 있는 것도 장점입니다.

3 · 적용 방식 — 2단계

14칸짜리 "빈칸 채우기 답안지"를 채웁니다

vtracer는 Needle3에게 빈 답안지를 주고 성적표를 보고 채우라고 합니다. 각 칸마다 허용 범위가 인쇄되어 있어서(예: 색 정밀도는 1~8) 답안지 형식 자체가 답을 지켜 줍니다.

이 답안지 양식을 JSON 스키마라고 부릅니다. Needle3는 문법 검사기가 붙은 모델이라 형식에 맞지 않는 답을 쓰는 것이 원천적으로 불가능합니다.

답과 함께 적어 주는 두 가지

근거(rationale) — "잡음이 적고 색이 15가지뿐이라 평면 그림으로 판단했습니다" 같은 한 줄 이유. 자신감(confidence) — 0~100% 숫자로, 이 판단이 얼마나 확실한지 표시합니다. 앱 화면에 그대로 보여 줍니다.

4 · 적용 방식 — 3단계

적용 전에 "안전 대조"를 거칩니다

모델의 답을 그대로 믿지 않습니다. vtracer 안에는 성적표만으로 답안지를 만드는 규칙 도우미(휴리스틱)가 상시 대기 중이고, 모델 답과 한 칸씩 대조합니다.

  • 모델이 비운 칸 → 규칙 도우미의 값으로 채웁니다.
  • 모델이 범위를 벗어난 답(예: 1~8인데 99) → 한계값(8)으로 잘라 냅니다. 이것을 클램프라고 합니다.
  • 고친 부분이 있으면 수복 표시를 남겨 나중에 확인할 수 있습니다.
결과

변환기(주방)에는 항상 올바른 범위의 설정 값만 도착합니다. 모델이 실수해도 최악의 답은 "규칙 도우미 수준"이 될 뿐, 엉터리 변환이 나올 수 없습니다.

사진을 불러옵니다 왼쪽 패널의 파일 선택을 누르거나 사진을 창으로 끌어다 놓으세요. → 화면에 사진이 나타나면 성공입니다.

목표를 고릅니다 AI 자동 섹션에서 균형(기본) / 충실(디테일 우선) / 경량(파일 크기 우선) 중 하나를 누르세요. → 선택한 버튼에 테두리가 생기면 성공입니다.
3
"분석 후 적용"을 누릅니다 잠깐 분석한 뒤 슬라이더들이 저절로 움직이고, 변환 결과가 바로 갱신됩니다. → 섹션 아래에 도우미 이름 · 자신감 % · 판단 이유가 표시되면 성공입니다.
4

6 · 따라하기 — 명령줄과 두 개의 두뇌

모델이 없어도 절대 멈추지 않습니다

AI 자동 모드에는 두뇌가 두 개 있고, Needle3는 앱 안에 내장되어 함께 배포됩니다. 기본 설정에서는 내장 Needle3가 판단하고 규칙 도우미가 답을 검사합니다. 모델을 사용할 수 없거나 모델이 답을 포기하면 자동으로 규칙 도우미가 대신합니다 — 기능이 실패로 끝나지 않습니다.

명령줄(CLI)에서 한 줄로 쓰기

vtracer --preset ai 사진.jpg 결과.svg  # 내장 규칙으로 자동 판단
vtracer --preset ai --ai-goal compact 사진.jpg 결과.svg  # 파일을 더 작게
vtracer --preset ai --needle3 http://127.0.0.1:8080/run 사진.jpg 결과.svg  # Needle3 서버 사용

--ai-goal 값: balanced(균형) · faithful(충실) · compact(경량). 모델 호출이 실패하면 규칙 도우미로 자동 전환됩니다.

7 · 문제가 생겼을 때

증상과 해결

증상이렇게 해보세요
"분석 후 적용" 버튼이 회색으로 눌리지 않아요 이미지를 먼저 불러오세요. 버튼은 사진이 열려 있을 때만 눌립니다.
"AI 자동 분석 실패"라는 메시지가 나와요 Needle3 서버 주소가 잘못되었을 수 있습니다. 설정에서 주소를 비우고 다시 누르면 내장 규칙으로 정상 동작합니다.
자신감이 낮게(예: 60%) 나와요 사진 성격이 평범하지 않다는 뜻입니다. 목표를 충실 또는 경량으로 바꿔 다시 분석해 보세요.
결과가 마음에 안 들어요 AI의 답은 훌륭한 출발점일 뿐입니다. 목표를 바꿔 다시 돌리거나, 슬라이더를 조금 손보면 됩니다.

8 · 용어 사전

어려운 말, 쉬운 말

비트맵 / 벡터(SVG)
비트맵은 칸칸이 색칠한 모자이크, 벡터는 선과 곡선으로 된 그림입니다. 벡터는 아무리 키워도 각지지 않습니다.
모델
학습으로 만든 작은 AI 두뇌입니다. Needle3는 앱에 내장되어 인터넷 없이도 실행됩니다.
피처 (성적표)
사진을 요약한 17개의 숫자입니다. 색 종류, 잡음, 선 밀도 등이 적힙니다.
JSON 스키마 (답안지 양식)
칸과 허용 범위가 정해진 빈칸 채우기 양식입니다. 모델이 형식을 벗어난 답을 못 하게 막습니다.
휴리스틱 (규칙 도우미)
"잡음이 적으면 잡점을 조금만 지운다" 같은 경험 규칙으로 판단하는 내장 두뇌입니다.
클램프
범위를 벗어난 답을 한계값으로 잘라 내는 안전장치입니다. 99를 1~8 범위에 맞추면 8이 됩니다.
